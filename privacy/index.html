Privacy Policy

Last updated: November 1, 2026

Stevie Workspace is a personal tool operated by Carlos Esteban López Sánchez. It is used only with the operator's own Google account and is not offered to the public.

Data it accesses

  • Gmail: messages, attachments, labels and drafts, plus sending mail when the operator requests it.
  • Google Calendar: events and calendars.

How the data is used

Only to run the operator's own automations: classifying and labeling mail, retrieving attachments, replying to messages and managing calendar events.

Sharing

Data is not sold, used for advertising, or shared with third parties, with one exception: message content may be sent to Anthropic's Claude AI service in order to classify mail. Messages the operator chooses to send naturally reach their recipients.

Storage and security

The automations run on infrastructure controlled by the operator. Credentials are stored as managed secrets, and access to that infrastructure is restricted. This public website collects no data, sets no cookies and uses no analytics.

Limited Use

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account permissions.

Contact

contacto@stevieworkspace.dev

Política de privacidad

Stevie Workspace es una herramienta personal operada por Carlos Esteban López Sánchez. Solo se usa con su propia cuenta de Google y no se ofrece al público.

Accede a: Gmail (mensajes, adjuntos, etiquetas, borradores y envío cuando el operador lo pide) y Google Calendar (eventos y calendarios).

Uso: únicamente para sus automatizaciones personales: clasificar y etiquetar correo, obtener adjuntos, responder mensajes y administrar eventos.

Compartición: los datos no se venden, no se usan para publicidad ni se comparten con terceros, con una excepción: el contenido de los mensajes puede enviarse al servicio de IA Claude de Anthropic para clasificar el correo.

Este sitio no recopila datos, no usa cookies ni analítica. El acceso se puede revocar en los permisos de tu cuenta de Google. Contacto: contacto@stevieworkspace.dev.
